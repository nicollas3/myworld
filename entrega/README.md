# Pacote para Visual Studio

`NeuroCare-VisualStudio.zip` contém a pasta `NeuroCare`, com a solução completa atualizada e a publicação compilada. Extraia o pacote e abra `NeuroCare/NeuroCare.sln` em um Visual Studio com suporte ao .NET 10.

O ZIP tem aproximadamente 31 MB (29,64 MiB). O arquivo `.sha256` permite conferir a integridade. A aplicação compilada está em `publicacao/`; SQL Server e configurações locais seguem as instruções do README dentro do pacote.

Os mesmos fontes também estão na raiz desta branch, com `NeuroCare.sln`, `src/`, `tests/` e documentação. Para obter apenas essa estrutura pelo botão Code → Download ZIP, a pasta `entrega/` pode ser removida após extrair; ela não é necessária para abrir a solução.
